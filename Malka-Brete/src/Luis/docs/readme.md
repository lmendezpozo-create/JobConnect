# Módulo de Postulaciones (Luis) — JobConnect

Este módulo es la sección encargada de la visualización y gestión de postulaciones laborales por parte de los candidatos.

## Funcionalidades
- Listado de postulaciones.
- Creación de nuevas postulaciones.
- Edición y eliminación de postulaciones activas.

## Uso
Abre `src/Luis/pages/Postulaciones/postulaciones.html` en tu navegador o ejecuta el servidor local con `npm run dev`.
